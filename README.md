# Temple of Horus

Prototipo original de Pilukarts: puzzle táctil de física y match-3 ambientado en un templo egipcio.

## Cómo jugar

Elige una columna para soltar una reliquia. Los grupos conectados de 3 o más símbolos iguales desaparecen y las piezas restantes caen por gravedad. Cada combinación carga el Ojo de Horus. Al completarlo se abre el Canal del Destino y un selector central reparte una lluvia de reliquias aleatorias.

## Identidad

- Puzzle de estrategia; no contiene apuestas ni dinero real.
- Símbolos: Ojo de Horus, escarabajo, ankh, sol, gema y león.
- Diseño responsive preparado para móvil.
- HTML, CSS y JavaScript sin dependencias.
